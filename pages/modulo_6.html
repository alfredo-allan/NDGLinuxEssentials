Módulo 6

Obtendo Ajuda no Linux

Aprenda a encontrar ajuda e documentação diretamente no terminal

6.1 Introdução

Existem milhares de comandos disponíveis com muitas opções, tornando a linha de comando uma ferramenta poderosa. No entanto, com esse poder vem a complexidade. A complexidade, por sua vez, pode criar confusão.

Como resultado, saber como encontrar ajuda enquanto trabalha no Linux é uma habilidade essencial para qualquer usuário. Consultar a ajuda fornece uma rápida lembrança de como um comando funciona, além de ser um recurso de informação ao aprender novos comandos.

Dica: Mesmo usuários avançados consultam as páginas de ajuda regularmente. Ninguém decora todas as opções de todos os comandos!

Por que a ajuda é importante?

O terminal do Linux oferece um controle granular sobre o sistema, mas essa flexibilidade significa que existem centenas de flags (opções) e parâmetros para cada comando. As fontes de ajuda embutidas no próprio sistema operacional são:

  • Rápidas - disponíveis sem sair do terminal
  • Precisas - sempre atualizadas com a versão instalada
  • Offline - funcionam sem conexão com a internet
Benefício: Dominar as ferramentas de ajuda (como man, info e --help) dobra sua produtividade no terminal.

6.2 Man Pages (Páginas do Manual)

UNIX é o sistema operacional no qual o Linux foi modelado. Os desenvolvedores do UNIX criaram documentos de ajuda chamados man pages (abreviação de manual pages - páginas do manual).

As man pages são usadas para descrever as funcionalidades dos comandos. Elas fornecem uma descrição básica do propósito do comando, bem como detalhes sobre as opções disponíveis.

Como usar o comando man

A sintaxe básica para acessar uma página de manual é:

man [comando]

Por exemplo, para ver o manual do comando ls:

man ls

Estrutura de uma Man Page

Toda man page segue uma estrutura padronizada que inclui as seguintes seções principais:

Seção Descrição
NAME Nome do comando e uma breve descrição
SYNOPSIS Sintaxe de uso do comando (como digitá-lo)
DESCRIPTION Explicação detalhada do funcionamento
OPTIONS Lista completa de flags e opções disponíveis
EXAMPLES Exemplos práticos de uso (em muitas páginas)
SEE ALSO Referências para outros comandos relacionados
As man pages são numeradas em seções: 1 (comandos do usuário), 2 (chamadas de sistema), 3 (bibliotecas), 5 (formatos de arquivo), 8 (comandos administrativos), etc.

Navegação dentro do man

Quando você abre uma man page, o terminal entra em um visualizador chamado less. Use estas teclas para navegar:

Tecla Ação
↑ / ↓ Rolar linha por linha
Page Up / Page Down Rolar página por página
/palavra Buscar por "palavra" no documento
n Próxima ocorrência da busca
q Sair do visualizador e voltar ao terminal
h Ajuda do visualizador less

Alternativas às Man Pages

Além do comando man, existem outras formas rápidas de obter ajuda:

comando --help
comando -h

A opção --help (ou -h) geralmente exibe um resumo mais curto e direto das opções principais, ideal para consultas rápidas.

Importante: Nem todos os comandos suportam --help da mesma forma. O padrão POSIX recomenda --help, mas programas mais antigos podem usar apenas -h ou não suportar nenhum dos dois. Nesses casos, use man.

Comandos sem man pages: built-in do shell

Alguns comandos são built-in (embutidos) no próprio shell (como cd, echo, exit). Para eles, use o comando help: 

help cd
help echo
Exercício sugerido: Execute man man para ler o manual do próprio comando man! É um ótimo ponto de partida.

6.2.1 Visualizando Páginas de Manual

Para visualizar uma página de manual (man page) de um comando, use o comando man:

man comando

Por exemplo, o seguinte comando exibe a página de manual para o comando ls:

sysadmin@localhost:~$ man ls

Navegue pelo documento usando as teclas de seta:

LS(1)                            User Commands                           LS(1)  
                                                                                
NAME                                                                            
       ls - list directory contents                                             
                                                                                
SYNOPSIS                                                                        
       ls [OPTION]... [FILE]...                                                 
                                                                                
DESCRIPTION                                                                     
       List  information  about  the FILEs (the current directory by default).  
       Sort entries alphabetically if none of -cftuvSUX nor --sort  is  speci-  
       fied.                                                                    
                                                                                
       Mandatory  arguments  to  long  options are mandatory for short options  
       too.                                                                     
                                                                                
       -a, --all                                                                
              do not ignore entries starting with .

Para sair da visualização de uma página de manual, use a tecla Q.

Considere isto: O comando man usa um paginador para exibir documentos. Normalmente, este paginador é o comando less, mas em algumas distribuições, pode ser o comando more. Ambos são muito semelhantes em seu funcionamento.

Para visualizar os vários comandos de movimento disponíveis, use a tecla H enquanto visualiza uma página de manual. Isso exibe uma página de ajuda.

Paginadores serão discutidos em mais detalhes posteriormente no curso.

6.2.2 Seções Dentro das Páginas de Manual

As páginas de manual (man pages) são divididas em seções. Cada seção é projetada para fornecer informações específicas sobre um comando. Embora existam seções comuns vistas na maioria das páginas de manual, alguns desenvolvedores também criam seções disponíveis apenas em páginas de manual específicas.

O seguinte descreve algumas das seções mais comuns encontradas nas páginas de manual:

NAME

Fornece o nome do comando e uma descrição muito breve.

NAME                                                                            
       ls - list directory contents

SYNOPSIS

Fornece exemplos de como o comando é executado.

SYNOPSIS                                                                        
       ls [OPTION]... [FILE]...

A seção SYNOPSIS de uma página de manual pode ser difícil de entender, mas é muito importante porque fornece um exemplo conciso de como usar o comando. Por exemplo, considere o SYNOPSIS da página de manual para o comando cal: 

SYNOPSIS 
     cal [-31jy] [-A number] [-B number] [-d yyyy-mm] [[month] year]

Os colchetes [ ] são usados para indicar que este recurso não é necessário para executar o comando. Por exemplo, [-31jy] significa que as opções -3, -1, -j ou -y estão disponíveis, mas não são necessárias para que o comando cal funcione corretamente.

O último conjunto de colchetes [[month] year] demonstra outro recurso; significa que um ano pode ser especificado por si só, mas para especificar um mês, o ano também deve ser especificado.

Outro componente do SYNOPSIS que pode causar alguma confusão pode ser visto na página de manual do comando date: 

SYNOPSIS                                                              
       date [OPTION]... [+FORMAT]                                      
       date [-u|--utc|--universal] [MMDDhhmm[[CC]YY][.ss]]

Neste SYNOPSIS existem duas sintaxes para o comando date. A primeira é usada para exibir a data no sistema, enquanto a segunda é usada para definir a data.

As reticências ... seguindo [OPTION] indicam que um ou mais dos itens antes dela podem ser usados.

Além disso, a notação [-u|--utc|--universal] significa que a opção -u ou a opção --utc ou a opção --universal pode ser usada. Tipicamente, isso significa que todas as três opções realmente fazem a mesma coisa, mas às vezes o uso do caractere | é usado para indicar que as opções não podem ser usadas em combinação, como um "ou" lógico.

DESCRIPTION

Fornece uma descrição mais detalhada do comando.

DESCRIPTION  
       List  information  about  the FILEs (the current directory by default).  
       Sort entries alphabetically if none of -cftuvSUX nor --sort  is  speci-  
       fied.

OPTIONS

Lista as opções para o comando, bem como uma descrição de como elas são usadas. Frequentemente, essa informação é encontrada na seção DESCRIPTION e não em uma seção OPTIONS separada. 

       -a, --all                                                                
              do not ignore entries starting with .  
 
       -A, --almost-all                                                         
              do not list implied . and ..                                      
                                                                                
       --author                                                                 
              with -l, print the author of each file                            
                                                                                
       -b, --escape                                                             
              print C-style escapes for nongraphic characters                   
                                                                                
       --block-size=SIZE                                                        
              scale sizes by SIZE before printing them; e.g., '--block-size=M'  
              prints sizes in units of 1,048,576 bytes; see SIZE format below

FILES

Lista os arquivos que estão associados ao comando, bem como uma descrição de como eles são usados. Esses arquivos podem ser usados para configurar os recursos mais avançados do comando. Frequentemente, essa informação é encontrada na seção DESCRIPTION e não em uma seção FILES separada.

AUTHOR

Fornece o nome da pessoa que criou a página de manual e (às vezes) como contatar a pessoa.

AUTHOR                                                                          
       Written by Richard M. Stallman and David MacKenzie.

REPORTING BUGS

Fornece detalhes sobre como relatar problemas com o comando.

REPORTING BUGS                                                                  
       GNU coreutils online help: <http://www.gnu.org/software/coreutils/>      
       Report ls translation bugs to <http://translationproject.org/team/>

COPYRIGHT

Fornece informações básicas de direitos autorais.

COPYRIGHT                                                                       
       Copyright (C) 2017 Free Software Foundation, Inc.  License GPLv3+:  GNU  
       GPL version 3 or later <http://gnu.org/licenses/gpl.html>.               
       This  is  free  software:  you  are free to change and redistribute it.  
       There is NO WARRANTY, to the extent permitted by law.

SEE ALSO

Fornece uma ideia de onde você pode encontrar informações adicionais. Isso frequentemente inclui outros comandos relacionados a este comando. 

SEE ALSO                                                                        
       Full documentation at: <http://www.gnu.org/software/coreutils/ls>        
       or available locally via: info '(coreutils) ls invocation'

6.2.3 Pesquisando em Páginas de Manual

Para pesquisar em uma página de manual por um termo, digite o caractere / seguido por um termo de pesquisa, então pressione a tecla Enter. O programa pesquisa a partir da localização atual em direção à parte inferior da página para tentar localizar e destacar o termo.

Se uma correspondência for encontrada, ela será destacada. Para mover para a próxima correspondência do termo, pressione n. Para retornar a uma correspondência anterior do termo, pressione Shift+N. Se o termo não for encontrado, ou ao atingir o final das correspondências, o programa reportará Pattern not found (pressione Return).

Exemplo: Buscando por "option" no man man

6.2.4 Páginas de Manual Categorizadas por Seções

Até agora, temos exibido páginas de manual para comandos. No entanto, existem vários tipos diferentes de comandos (comandos de usuário, comandos de sistema e comandos de administração), arquivos de configuração e outros recursos, como bibliotecas e componentes do kernel, que exigem documentação.

Como resultado, existem milhares de páginas de manual em uma distribuição Linux típica. Para organizar todas essas páginas de manual, elas são categorizadas por seções.

Por padrão, existem nove seções de páginas de manual:

  • 1 - Comandos Gerais
  • 2 - Chamadas de Sistema
  • 3 - Chamadas de Biblioteca
  • 4 - Arquivos Especiais
  • 5 - Formatos de Arquivo e Convenções
  • 6 - Jogos
  • 7 - Diversos
  • 8 - Comandos de Administração do Sistema
  • 9 - Rotinas do Kernel

O comando man pesquisa cada uma dessas seções em ordem até encontrar a primeira correspondência. Por exemplo, se você executar o comando man cal, a primeira seção (Comandos Gerais) é pesquisada por uma página de manual chamada cal. Se não for encontrada, então a segunda seção é pesquisada. Se nenhuma página de manual for encontrada após pesquisar todas as seções, uma mensagem de erro é retornada: 

sysadmin@localhost:~$ man zed                                          
No manual entry for zed

Para determinar a qual seção uma página de manual específica pertence, olhe para o valor numérico na primeira linha da saída da página de manual. Por exemplo, o comando cal pertence à primeira seção das páginas de manual: 

CAL(1)                    BSD General Commands Manual             CAL(1)

Às vezes, existem páginas de manual com o mesmo nome em diferentes seções. Nestes casos, pode ser necessário especificar a seção da página de manual correta.

Por exemplo, existe um comando chamado passwd que permite que você altere sua senha. Existe também um arquivo chamado passwd que armazena informações de conta. Tanto o comando quanto o arquivo têm uma página de manual.

O comando passwd é um comando de usuário, então a página de manual associada está na primeira seção. O comando man exibe a página de manual para o comando passwd por padrão: 

sysadmin@localhost:~$ man passwd

PASSWD(1)                        User Commands                 PASSWD(1)

Então, como você exibe a página de manual para o arquivo passwd? Primeiro, determine em qual seção a página de manual está localizada. Para pesquisar páginas de manual por nome, use a opção -f no comando man. Ela exibe páginas de manual que correspondem, ou correspondem parcialmente, a um nome específico e fornece o número da seção e uma breve descrição de cada página de manual: 

sysadmin@localhost:~$ man -f passwd                                    
passwd (5)           - the password file                              
passwd (1)           - change user password                           
passwd (1ssl)        - compute password hashes
Nota: Na maioria das distribuições Linux, o comando whatis faz a mesma coisa que man -f. Nessas distribuições, ambos produzirão a mesma saída.

Para especificar uma seção diferente, forneça o número da seção como o primeiro argumento do comando man. O seguinte comando exibe a página de manual passwd localizada na seção 5, que está associada ao arquivo passwd: 

sysadmin@localhost:~$ man 5 passwd

PASSWD(5)                File Formats and Conversions          PASSWD(5)

Infelizmente, você nem sempre vai se lembrar do nome exato da página de manual que deseja visualizar. Felizmente, cada página de manual tem uma breve descrição associada a ela. A opção -k no comando man pesquisa tanto os nomes quanto as descrições das páginas de manual por uma palavra-chave.

Por exemplo, para encontrar uma página de manual que exibe como copiar diretórios, pesquise pela palavra-chave copy: 

sysadmin@localhost:~$ man -k copy                                               
cp (1)               - copy files and directories                               
cpgr (8)             - copy with locking the given file to the password or gr...
cpio (1)             - copy files to and from archives                          
cppw (8)             - copy with locking the given file to the password or gr...
dd (1)               - convert and copy a file                                  
debconf-copydb (1)   - copy a debconf database                                  
install (1)          - copy files and set attributes                            
scp (1)              - secure copy (remote file copy program)                   
ssh-copy-id (1)      - use locally available keys to authorize logins on a re...

Lembre-se de que existem milhares de páginas de manual, então, ao pesquisar por uma palavra-chave, seja o mais específico possível. Usar uma palavra genérica, como "the", poderia resultar em centenas ou até milhares de resultados.

Nota: Na maioria das distribuições Linux, o comando apropos faz a mesma coisa que man -k. Nessas distribuições, ambos produzem a mesma saída.

6.3 Encontrando Comandos e Documentação

O comando whatis (ou man -f) retorna em qual seção uma página de manual está armazenada. Este comando ocasionalmente retorna uma saída incomum, como a seguinte: 

sysadmin@localhost:~$ whatis ls                                              
ls (1)               - list directory contents 
ls (lp)              - list directory contents
Nota: O exemplo acima é projetado para demonstrar um cenário onde dois comandos listam o conteúdo de diretórios. A saída no exemplo do terminal acima pode não corresponder à saída na VM.

Com base nesta saída, existem dois comandos ls que listam o conteúdo de diretórios. A razão simples para isso é que o UNIX tinha duas variantes principais, o que resultou em alguns comandos sendo desenvolvidos "em paralelo" e, portanto, comportando-se de maneira diferente em diferentes variantes do UNIX. Muitas distribuições modernas do Linux incluem comandos de ambas as variantes do UNIX.

Isso, no entanto, representa um pequeno problema: quando o comando ls é digitado, qual comando é executado?

6.3.1 Onde Esses Comandos Estão Localizados?

Para pesquisar a localização de um comando ou das páginas de manual para um comando, use o comando whereis. Este comando pesquisa por comandos, arquivos fonte e páginas de manual em locais específicos onde esses arquivos são tipicamente armazenados: 

sysadmin@localhost:~$ whereis ls 
ls: /bin/ls /usr/share/man/man1p/ls.1.gz /usr/share/man/man1/ls.1.gz

As páginas de manual são facilmente distinguidas dos comandos, pois são tipicamente compactadas com um programa chamado gzip, resultando em um nome de arquivo que termina em .gz. Observe que há duas páginas de manual listadas acima, mas apenas um comando: /bin/ls. Isso ocorre porque o comando ls pode ser usado com as opções/recursos que são descritos por qualquer uma das páginas de manual. Então, ao aprender o que pode ser feito com o comando ls, pode ser interessante explorar ambas as páginas de manual. Felizmente, isso é mais uma exceção, pois a maioria dos comandos tem apenas uma página de manual.

6.3.2 Encontrando Qualquer Arquivo ou Diretório

O comando whereis é especificamente projetado para encontrar comandos e páginas de manual. Embora isso seja útil, muitas vezes é necessário encontrar um arquivo ou diretório, não apenas arquivos que são comandos ou páginas de manual.

Para encontrar qualquer arquivo ou diretório, use o comando locate. Este comando pesquisa um banco de dados de todos os arquivos e diretórios que estavam no sistema quando o banco de dados foi criado. Tipicamente, o comando para gerar este banco de dados é executado todas as noites. 

sysadmin@localhost:~$ locate gshadow                                   
/etc/gshadow                                                           
/etc/gshadow-                                                          
/usr/include/gshadow.h                                                
/usr/share/man/cs/man5/gshadow.5.gz                                   
/usr/share/man/da/man5/gshadow.5.gz                                    
/usr/share/man/de/man5/gshadow.5.gz                                    
/usr/share/man/fr/man5/gshadow.5.gz                                    
/usr/share/man/it/man5/gshadow.5.gz                                    
/usr/share/man/man5/gshadow.5.gz                                       
/usr/share/man/ru/man5/gshadow.5.gz                                   
/usr/share/man/sv/man5/gshadow.5.gz                                    
/usr/share/man/zh_CN/man5/gshadow.5.gz

Quaisquer arquivos criados hoje não serão pesquisáveis com o comando locate. Se o acesso root estiver disponível, é possível atualizar o banco de dados do locate manualmente executando o comando updatedb. Usuários comuns não podem atualizar o arquivo de banco de dados.

Observe também que ao usar o comando locate como um usuário comum, a saída pode ser limitada devido às permissões de arquivo. Se o usuário que está logado não tem acesso a um arquivo ou diretório no sistema de arquivos devido a permissões, o comando locate não retornará esses nomes. Este recurso de segurança é projetado para impedir que usuários "explorem" o sistema de arquivos usando o banco de dados do locate. O usuário root pode pesquisar qualquer arquivo no banco de dados do locate.

A saída do comando locate pode ser bastante grande. Ao pesquisar por um nome de arquivo, como passwd, o comando locate produz cada arquivo que contém a string passwd, não apenas arquivos nomeados passwd.

Em muitos casos, é útil começar descobrindo quantos arquivos correspondem. Faça isso usando a opção -c no comando locate: 

sysadmin@localhost:~$ locate -c passwd                                 
98

Para limitar a saída produzida pelo comando locate, use a opção -b. Esta opção inclui apenas listagens que têm o termo de busca no basename do nome do arquivo. O basename é a porção do nome do arquivo que não inclui os nomes dos diretórios. 

sysadmin@localhost:~$ locate -c -b passwd                              
83

Como você pode ver na saída anterior, ainda haverá muitos resultados quando a opção -b for usada. Para limitar ainda mais a saída, coloque um caractere \ na frente do termo de busca. Este caractere limita a saída a nomes de arquivo que correspondem exatamente ao termo: 

sysadmin@localhost:~$ locate -b "\passwd"                              
/etc/passwd                                                                     
/etc/pam.d/passwd                                                               
/usr/bin/passwd                                                                 
/usr/share/doc/passwd                                                           
/usr/share/lintian/overrides/passwd

6.4 Documentação Info

As páginas de manual (man pages) são fontes excelentes de informação, mas elas tendem a ter algumas desvantagens. Um exemplo é que cada página de manual é um documento separado, não relacionado a nenhuma outra página de manual. Embora algumas páginas de manual tenham uma seção SEE ALSO que pode se referir a outras páginas de manual, elas tendem a ser fontes de documentação independentes.

O comando info também fornece documentação sobre comandos e recursos do sistema operacional. O objetivo é ligeiramente diferente das páginas de manual: fornecer um recurso de documentação que dá uma estrutura organizacional lógica, tornando a leitura da documentação mais fácil.

Toda a documentação é mesclada em um único "livro" representando toda a documentação disponível. Dentro dos documentos info, a informação é dividida em categorias que funcionam muito como um sumário em um livro. Hiperlinks são fornecidos para páginas com informações sobre tópicos individuais para um comando ou recurso específico.

Outra vantagem do info sobre as páginas de manual é que o estilo de escrita dos documentos info é tipicamente mais propício para aprender um tópico. Considere as páginas de manual como sendo mais um recurso de referência e os documentos info como sendo mais um guia de aprendizado.

6.4.1 Exibindo Documentação Info

Para exibir a documentação info para um comando, use o comando info.

info comando

Por exemplo, para exibir a página info do comando ls:

sysadmin@localhost:~$ info ls

6.5 Fontes Adicionais de Ajuda

Em muitos casos, as páginas de manual ou a documentação info fornecem as informações necessárias de maneira eficiente. No entanto, existem outras fontes de ajuda que devemos conhecer.

6.5.1 Usando a Opção de Ajuda

Muitos comandos fornecem informações básicas, muito semelhantes ao SYNOPSIS encontrado nas páginas de manual, simplesmente usando a opção --help no comando. Esta opção é útil para aprender o uso básico de um comando rapidamente, sem sair da linha de comando:

6.5.2 Documentação Adicional do Sistema

Na maioria dos sistemas, existe um diretório onde documentação adicional (como arquivos de documentação armazenados por fornecedores de software de terceiros) é encontrada.

Esses arquivos de documentação são frequentemente chamados de arquivos readme, pois os arquivos tipicamente têm nomes como README ou readme.txt. A localização desses arquivos pode variar dependendo da distribuição que você está usando. Localizações típicas incluem /usr/share/doc e /usr/doc.

Tipicamente, este diretório é onde os administradores de sistema vão para aprender como configurar serviços de software mais complexos. No entanto, às vezes usuários comuns também acham esta documentação útil.
