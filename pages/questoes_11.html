    • Q2 Lógica do Script mkdir

    O que o seguinte trecho de script realiza? 
    FOO=/tmp/foo
if [ ! -d $FOO ]; then
    mkdir $FOO
fi
  • Cria o diretório /tmp/foo se ele não existir.
  • Remove o diretório /tmp/foo caso ele exista no sistema.
  • Apresenta uma mensagem de erro na tela de saída.
  • Não realiza nada, pois possui erros de sintaxe estrutural.

    • Q3 Loops for e while

    Qual das seguintes afirmações descreve corretamente o funcionamento dos laços for e while?
  • Os loops for realizam testes condicionais e loops while operam apenas sobre listas fixas.
  • Loops while avaliam uma condição a cada ciclo e loops for operam sobre uma lista estipulada de itens.
  • Ambos exigem listas estáticas e não realizam verificações dinâmicas de fim de bloco.
  • O loop while roda obrigatoriamente um número fixo de 10 iterações por padrão.

    • Q7 Variável especial $?

    Qual tipo de informação é armazenado na variável interna especial $? ?
  • O ID do processo em execução em primeiro plano.
  • O código de término (exit code) do último comando executado.
  • O número total de parâmetros passados para o shell script.
  • O nome exato do arquivo binário do interpretador.

    • Q10 Comportamento do Laço

    Analise o seguinte código: 
    while [ ! -f /tmp/foo ]; do
    echo -n "."
    process_data > /tmp/foo
done
    Se o arquivo /tmp/foo não existir antes do início da execução, o que acontecerá?
  • O loop rodará indefinidamente preenchendo a tela com pontos.
  • O comando process_data será chamado no máximo uma única vez.
  • O script quebrará apresentando erro porque o arquivo não existia.
  • O comando process_data nunca chegará a ser acionado.
