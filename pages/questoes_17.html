Q1 Métodos do comando chmod

Quais das seguintes alternativas representam métodos válidos para a configuração e modificação de permissões através do comando chmod? (escolha duas)
  • primary
  • octal
  • symbolic
  • letter

    • Q2 Permissões Máximas em Diretório

    Qual das seguintes configurações de permissão octal permitiria que absolutamente todos os usuários do sistema criassem, visualizassem e deletassem arquivos dentro de um diretório específico?
  • 777

  • 666
  • 750

    • Q3 Exclusão de Arquivos e Propriedade

    Um usuário comum está categoricamente impedido de deletar um arquivo do sistema caso ele não seja o proprietário (dono) legítimo desse arquivo.
  • Verdadeiro

    • Q4 Propósito do Bit de Execução

    A atribuição da permissão de execução (x) sobre um arquivo regular confere ao usuário o direito de:
  • Rodar o arquivo como um script ou processo binário
  • Mover o arquivo para um novo diretório
  • Deletar o arquivo
  • Nenhuma das alternativas; essa permissão não possui significado para arquivos de texto

    • Q5 Restrições de Uso do comando chmod

    O comando chmod pode ser operado em um arquivo por:
  • O proprietário do arquivo e o usuário root
  • Apenas pelo proprietário do arquivo
  • Apenas pelo usuário root
  • Qualquer usuário que pertença ao grupo proprietário do arquivo

    • Q6 Herança de Execução e umask

    A permissão de execução nunca é atribuída a arquivos de forma automática por padrão no momento de sua criação.

    • Q7 Sintaxe Completa do chown

    Quais dos seguintes comandos chown alterarão simultaneamente o usuário proprietário do arquivo myFile para sam e o grupo proprietário para administrators? (escolha duas)
  • chown sam.administrators myFile
  • chown sam+administrators myFile
  • chown sam administrators myFile
  • chown sam:administrators myFile
