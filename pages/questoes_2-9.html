    Virtualização significa:
  • Um único host pode ser dividido em múltiplos guests
  • Dois usuários obtêm espaços de memória diferentes na mesma máquina
  • Um usuário pode se conectar a um servidor pela rede e usar um console virtual

    • Q11 O que é código-fonte?

    Código-fonte se refere a:
  • A versão de um programa que o computador executa na CPU
  • Uma versão legível por humanos de um software de computador
  • A licença que dita como você pode usar e compartilhar o software
  • A interface que o software usa para se comunicar com o kernel

    • Q12 Open source significa

    Open source significa: (escolha duas)
  • Você deve suportar o software que compartilha
  • Você deve compartilhar suas modificações
  • Você pode modificar o código-fonte do software
  • Você pode visualizar o código-fonte do software
  • Você não pode cobrar nada pelo software

    • Q13 Copyleft

    Uma cláusula copyleft em uma licença de software significa:
  • Você deve fornecer suporte para suas modificações
  • Você renuncia ao seu copyright sobre o software
  • Você deve fornecer cópias gratuitas do software se o usar
  • Você não pode vincular a software de terceiros de código fechado
  • Se redistribuir o software, você deve distribuir o código-fonte das suas alterações

    A compressão de um arquivo funciona:
  • Removendo informações redundantes
  • Removendo o bit de ordem superior de cada byte
  • Armazenando a maioria dos dados em mídia removível e deixando apenas um ponteiro

    • Q37 Compressão com perda

    Compressão com perda (lossy): (escolha três)
  • É frequentemente usada com documentos
  • Descomprime para uma versão idêntica à original
