Archiving and Compression - Teste seus conhecimentos sobre tar, gzip, bzip2, zip e compactação

Q1 Como funciona a compactação

A compactação de um arquivo funciona:
  • Eliminando lacunas dentro do arquivo
  • Armazenando a maioria dos dados em mídia removível e deixando apenas um ponteiro
  • Consolidando múltiplos arquivos em um
  • Removendo informações redundantes
  • Removendo o bit de ordem alta de cada byte

    • Q2 Compactação sem perda

    Em geral, para qual dos seguintes você usaria compactação sem perda (lossless)?
  • Um arquivo de log (log file)
  • Um filme
  • Um e-mail criptografado
  • Uma imagem JPEG
  • Um arquivo de áudio mp3

    • Q3 Compactação com perda

    A compactação com perda (lossy): (escolha três)
  • Descompacta para uma versão idêntica ao original
  • Geralmente resulta em melhor compactação do que a sem perda
  • É frequentemente usada com documentos
  • É frequentemente usada com imagens
  • Sacrifica alguma qualidade

    • Q4 Comando tar

    Dado o comando tar –cvjf homedirs.tbz /home, quais das seguintes afirmações são verdadeiras? (escolha duas)
  • O diretório /home será restaurado com o conteúdo de homedirs.tbz
  • Apenas arquivos começando com /home serão extraídos do arquivo
  • Arquivos presentes no arquivo podem sobrescrever arquivos em /home
  • O comando imprimirá cada nome de arquivo conforme for processado
  • O arquivo de saída será compactado

    • Q5 Extrair arquivos com tar

    Você arquivou os diretórios dos seus usuários em um arquivo chamado backup.tar.gz. Ao visualizar o arquivo, os nomes seguem esta convenção: home/username/somefile. Como você extrairá apenas os arquivos do usuário chamado fred?
  • tar –xzf backup.tar.gz fred
  • tar –tjf backup.tar.gz /home/fred
  • tar –xzf backup.tar.gz home/fred/
  • tar –xjf backup.tar.gz home/fred/
  • tar –tzf /home/fred < backup.tar.gz

    • Q6 Criar arquivo zip

    Qual dos seguintes comandos criará um arquivo zip com o conteúdo do diretório Documents?
  • zip -cf mydocs.zip Documents
  • zip –c mydocs.zip Documents
  • zip -r mydocs.zip Documents
  • zip –f mydocs.zip Documents
  • zip mydocs.zip Documents

    • Q7 Extrair zip específico

    Dado um arquivo chamado documents.zip, como você pode extrair apenas os arquivos dentro de ProjectX?
  • unzip documents.zip | grep ProjectX
  • unzip documents.zip ProjectX
  • unzip -t documents.zip ProjectX
  • zip -x documents.zip ProjectX
  • unzip documents.zip ProjectX/*

    • Q8 Opção -f do tar

    No comando tar -czf foo.tar.gz bar, qual é o propósito da opção f?
  • Especifica que compressão extra deve ser usada
  • Diz ao tar para imprimir o nome de cada arquivo conforme processado
  • Diz ao tar para copiar apenas arquivos, e não diretórios
  • Diz ao tar para ler do arquivo que segue a opção
  • Diz ao tar para escrever no arquivo que segue a opção

    • Q9 Comandos equivalentes

    Quais dois comandos fazem a mesma coisa? (escolha duas)
  • tar -tzf foo.tar.gz
  • tar -xzf foo.tar.gz
  • tar -czf foo.tar.gz foo
  • tar -c foo | gzip > foo.tar.gz
  • tar -x foo | gzip

    • Q10 zip substitui arquivos?

    Por padrão, o comando zip substitui arquivos descompactados por arquivos compactados.
