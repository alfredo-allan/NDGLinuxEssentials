Open Source Software and Licensing - Teste seus conhecimentos sobre licenças e software livre

Q1 Acesso ao código-fonte do Linux

O código-fonte do Linux está disponível para:
  • Qualquer pessoa que tenha o conhecimento necessário para acessá-lo
  • Apenas funcionários da Linux Foundation
  • Apenas pesquisadores universitários com bolsa do governo
  • Funcionários do FBI, CIA e NSA com autorização de alto sigilo

    • Q2 O que é código-fonte?

    Código-fonte se refere a:
  • A interface que o software usa para se comunicar com o kernel
  • A versão de um programa que o computador executa na CPU
  • Uma versão legível por humanos de um software de computador
  • A licença que dita como você pode usar e compartilhar o software

    • Q3 GPLv2 vs BSD

    A maior diferença entre as licenças GPLv2 e BSD é:
  • Apenas BSD permite uso comercial
  • Nada, elas são virtualmente idênticas
  • GPLv2 não é aprovada pela OSI
  • BSD não tem cláusula de copyleft
  • GPLv2 exige atribuição de copyright à FSF

    • Q4 Licença do Linux

    O Linux é distribuído sob qual licença?
  • GPLv3
  • MIT
  • GPLv2
  • Linux Foundation
  • BSD

    • Q7 CC BY-ND

    Se um podcast é licenciado sob CC BY-ND, você pode: (escolha duas)
  • Publicá-lo em seu site
  • Compartilhá-lo desde que dê crédito ao autor
  • Usar uma entrevista ou música dele para seu próprio podcast
  • Adicionar anúncios e publicá-lo em seu site
  • Vendê-lo como parte de uma compilação

    • Q8 GPL vs LGPL

    A diferença entre as licenças GPL e LGPL é:
  • LGPL se aplica a serviços web
  • LGPL permite distribuir o software apenas em formato binário
  • LGPL garante que todas as variantes do programa GPL original tenham a mesma liberdade de uso que o original
  • LGPL é mais curta que a GPL
  • LGPL foi feita pela OSI enquanto GPL foi feita pela FSF

    • Q9 Licenças de software livre permissivas

    Licenças de software livre permissivas: (escolha três)
  • Não têm cláusula de copyleft
  • Não são aprovadas pela FSF
  • Não são aprovadas pela OSI
  • Incluem GPLv2 e BSD
  • Podem permitir que o software seja usado dentro de software de código fechado

    • Q10 Creative Commons e Domínio Público

    A versão Creative Commons da licença de Domínio Público é:
  • NoAttribution-ShareAlike (CC BY-SA)
  • No Rights Reserved (CC0)
  • Attribution-NonCommercial (CC BY-NC)
  • Attribution-NonCommercial-ShareAlike (CC BY-NC-SA)
  • Attribution (CC BY)
