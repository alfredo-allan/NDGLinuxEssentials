Revisão Comandos e Conceitos

Lembre-se: PATH diretórios de busca, which localiza comando, echo exibe texto, && executa se anterior for sucesso, ! histórico, aspas duplas permitem variáveis e crases (` `) executam subcomando. 

$ echo $PATH
/usr/local/bin:/usr/bin:/bin
$ which ls
/bin/ls
$ mkdir test && cd test   # só entra se mkdir funcionar
$ echo "Usuário: $USER, data: $(date +%Y)"

Gabarito Respostas e Explicações

Clique para ver o gabarito completo
  1. PATH - Contém os diretórios onde o shell procura por executáveis.
  2. which - Localiza o caminho completo de um comando.
  3. Falso - Aspas duplas permitem expansão de variáveis e comandos.
  4. Verdadeiro - Crases executam o comando interno e substituem pela saída.
  5. Falso - && executa o da direita APENAS se o da esquerda for bem-sucedido.
  6. echo - Comando padrão para exibir mensagens no terminal.
  7. !5 - Reexecuta o quinto comando do histórico.
  8. Command Line Interface - Interface de linha de comando.
  9. Barra invertida (\) - Caractere de escape.
  10. Bash - Shell padrão na maioria das distribuições Linux.
