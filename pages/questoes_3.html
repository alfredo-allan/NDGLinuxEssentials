    • Q5 Cloud Computing

    Computação em nuvem (Cloud Computing):
  • Requer menos recursos porque os sistemas são compartilhados entre muitos usuários
  • É possível graças a velocidades de internet mais rápidas
  • Permite que usuários em diferentes regiões geográficas trabalhem juntos em tempo real
  • Todas estão corretas
  • É útil tanto para empresas quanto para usuários domésticos

    • Q7 Sistema Multiusuário

    Quais das seguintes são características de um sistema operacional multiusuário? (escolha três)
  • Usuários podem proteger suas informações de outros usuários
  • Cada usuário só pode fazer login uma vez por dia
  • Recursos são compartilhados entre usuários
  • Muitos usuários podem fazer login simultaneamente com uma conta única
  • Muitos usuários podem fazer login simultaneamente com contas únicas
  • Um usuário administrativo recebe uma CPU dedicada

    • Q9 Propriedades de uma Senha Forte

    Quais das seguintes são propriedades de uma senha forte? (escolha três)
  • Inclui símbolos
  • Baseada em itens fáceis de lembrar como aniversários
  • Longa para que possa ser reutilizada em múltiplos sites
  • Mistura de maiúsculas e minúsculas
  • Pelo menos 10 caracteres de comprimento

    • Q10 Prevenir Acesso Remoto Não Autorizado

    O que pode ser feito para prevenir que usuários não autorizados acessem seu computador remotamente? (escolha duas)
  • Usar senhas fortes em todas as contas de usuário
  • Bloquear cookies de terceiros
  • Ligar um firewall
  • Não usar redes sem fio - apenas com fio
  • Bloquear todos os cookies
