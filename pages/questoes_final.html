Q1 Definição de Sistemas Embarcados

O termo "Sistemas Embarcados" (Embedded Systems) significa:
  • Sistemas operacionais projetados para executar bancos de dados genéricos em nuvem
  • Sistemas projetados para realizar uma tarefa específica em hardware otimizado apenas para essa finalidade
  • Rotinas de firmware usadas para formatar partições de disco dinamicamente

    • Q2 Plataforma de Destino Original do Linux

    Originalmente, o Linux funcionava apenas em:
  • Microcontroladores Motorola 68000
  • PCs Intel 386
  • Arquiteturas PowerPC Macintosh

    • Q3 O Conceito de uma Distribuição Linux

    O agrupamento de utilitários, ferramentas de gerenciamento e softwares aplicativos junto ao Kernel Linux é chamado de:
  • Extensão customizada do Kernel
  • Uma distribuição Linux
  • Imagem de sistema monolítica

    • Q4 Ciclo de Lançamento de Software

    Um ciclo de lançamento de software (release cycle) descreve:
  • Com que frequência o hardware deve ser atualizado para suportar novos programas
  • Com que frequência um projeto de software lança novas versões, atualizações ou patches de estabilidade
  • O tempo total necessário para compilar um componente de software a partir do código-fonte

    Sobre o Microsoft Windows: (escolha três)
  • Possui um ambiente de scripts chamado PowerShell
  • Oferece produtos tanto para desktop quanto para servidores
  • Geralmente é retrocompatível com versões anteriores de software
  • É fundamentalmente gerenciado sob licenças de código aberto

  • Tende a oferecer mais recursos ou maior flexibilidade abstrata de dados do que linguagens compiladas
  • Requer compilação direta em binários ELF estáticos nativos antes da execução

  • Um host é uma máquina virtual

    • Q8 Definição de Computação em Nuvem

    Computação em nuvem (Cloud computing) é:
  • Alocação sob demanda de pools de recursos altamente escaláveis via rede
  • Tarifação baseada no uso dinâmico de instâncias virtuais compartilhadas
  • Provisionamento instantâneo de pilhas computacionais sem necessidade de engenharia física manual
  • Todas as alternativas estão corretas
